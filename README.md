## 🎯 프로젝트 개요

B7-1에서 개발한 AI 챗봇 서비스를 고도화합니다. 회원가입/로그인, 게시판, 대화 내역 영속화, 다중 사용자 지원 등 실제 서비스 수준으로 기능을 확장합니다.

## 🎓 학습 목표

이 과제를 완료한 뒤, 다음을 설명할 수 있어야 한다:

1. 회원가입/로그인/인증 시스템을 구현할 수 있다
2. 게시판 기능(CRUD)을 추가할 수 있다
3. 다중 사용자 환경에서 개인별 데이터를 분리할 수 있다
4. PR 기반 협업과 팀원별 커밋 기록을 관리할 수 있다
5. 배포 환경에서 모든 기능이 정상 동작하게 할 수 있다

## ⚠️ 제약 사항

- API 키, DB 비밀번호 등 민감 정보는 소스 코드에 직접 작성하지 않는다
- 모든 민감 정보는 .env 파일을 통해 환경 변수로 관리
- 모든 팀원은 최소 10회 이상의 유의미한 커밋 생성
- main 브랜치에 직접 푸시 금지, Pull Request를 통해서만 병합
